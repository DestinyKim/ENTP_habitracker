# 📊 습관 트래커 - PWA 버전

**ENTP를 위한 게임화 습관 관리 앱**

## ✨ 주요 기능

- 🎮 **레벨 시스템**: 매일 습관을 완료하면 경험치 적립 → 레벨업
- 📊 **대시보드**: 오늘의 습관, 연속 기록(streak), 현재 레벨 한눈에 보기
- 📈 **통계**: 지난 7일 습관 이행 현황과 습관별 이행률
- 🤔 **회고**: 주간 성과를 기록하고 정리하기
- 💾 **오프라인 지원**: 인터넷 없어도 앱 사용 가능
- 📱 **아이폰 앱처럼**: 홈 화면에 설치해서 앱처럼 사용

## 🚀 설치 방법

### iPhone에 설치하기 (가장 쉬움!) ⭐

1. **파일 다운로드**
   - 이 폴더의 파일 3개를 모두 다운로드
   - `index.html`, `manifest.json`, `service-worker.js`

2. **웹 서버에 업로드** (선택: 로컬에서 사용시 생략 가능)
   - Netlify, Vercel, GitHub Pages 등에 업로드
   - 또는 컴퓨터의 웹 폴더에 저장

3. **iPhone의 Safari에서 열기**
   - URL을 입력해서 접속
   - 하단의 **공유** 버튼 (네모에서 화살표) 클릭
   - **"홈 화면에 추가"** 선택
   - 이름 입력 후 **추가** 클릭
   - 완료! 홈 화면에 앱이 생성됨

### Mac/PC에서 사용하기

1. 파일 3개를 같은 폴더에 저장
2. `index.html`을 Chrome, Edge, Safari에서 열기
3. 완전한 기능 사용 가능

### 로컬 웹 서버로 실행하기

```bash
# Python 3 사용
python -m http.server 8000

# 또는 Node.js의 http-server 사용
npx http-server

# 브라우저에서 http://localhost:8000 열기
```

## 📖 사용 방법

### 대시보드 탭 (📊)
- **오늘의 습관**: 각 습관을 클릭해서 완료 표시
- **경험치**: 습관 완료 시 +10 XP 획득
- **레벨 시스템**: 100 XP마다 레벨업
- **연속 기록**: 얼마나 오래 지속했는지 확인

### 통계 탭 (📈)
- **7일 습관 이행**: 지난 1주일 습관 완성도 시각화
- **습관별 이행률**: 각 습관의 달성 비율을 % 표시
- **패턴 분석**: 어떤 습관이 약한지 한눈에 파악

### 회고 탭 (🤔)
- **자유 기록**: 주간 성과와 개선점 작성
- **통계 요약**: 그주의 습관 완성도와 획득 경험치 표시

## 🎯 습관 목록

기본 설정된 3가지 습관:
1. 💰 아임웹 수익화 달성
2. 💪 건강을 위한 운동
3. 📚 독서

## 💾 데이터 보관

- 모든 데이터는 **브라우저의 로컬 스토리지**에 저장
- 삭제하지 않는 한 계속 보관됨
- 다른 기기/브라우저에서 동기화 안 됨 (개인 정보 보호)
- 초기화: 브라우저의 캐시/쿠키 삭제 또는 개발자도구 > Storage > LocalStorage 삭제

## 🔒 개인정보

- ✅ 서버로 데이터 전송 없음
- ✅ 앱 내에서만 저장
- ✅ 완벽한 개인정보 보호

## ⚙️ 커스터마이징

### 습관 변경하기
`index.html` 파일을 텍스트 에디터(VS Code, 메모장 등)로 열고:

```javascript
const HABITS = [
    { id: 'aimp', name: '아임웹 수익화', icon: '💰', color: '#378ADD' },
    { id: 'exercise', name: '운동', icon: '💪', color: '#639922' },
    { id: 'reading', name: '독서', icon: '📚', color: '#BA7517' }
];
```

여기서 `name`과 `icon`을 원하는 대로 변경할 수 있습니다.

### 포인트 변경하기
```javascript
const POINTS_PER_HABIT = 10;        // 한 습관당 포인트
const POINTS_PER_LEVEL = 100;       // 레벨업에 필요한 포인트
```

## 🌐 배포 (온라인 공유)

### Netlify에 배포하기 (무료)

1. [netlify.com](https://netlify.com) 방문
2. GitHub 계정으로 로그인
3. 파일들을 GitHub 레포에 업로드
4. Netlify와 연결하면 자동 배포

### GitHub Pages에 배포하기

1. GitHub 저장소 생성 (`username.github.io`)
2. 파일 업로드
3. `https://username.github.io` 주소로 접속 가능

## 📱 ENTP에게 최적화된 이유

1. **게임화로 흥미 유지** - 단순 체크리스트가 아닌 레벨업 시스템
2. **분석 욕구 충족** - 통계와 차트로 패턴 분석
3. **회고 기능** - 단순 추적이 아닌 사고의 정리 시간 제공
4. **유연한 구조** - 습관 추가/제거가 쉬움
5. **즉각적 피드백** - 프로그레스 바와 포인트로 성취감 경험

## 🐛 문제 해결

### "홈 화면에 추가"가 안 나온다면
- iPhone 설정 > Safari > 개인정보 보호 > 추적 방지 비활성화
- 웹사이트를 다시 열고 시도

### 데이터가 사라진다면
- Safari의 "사이트 데이터 삭제"를 하지 않았는지 확인
- 미리 다른 브라우저에도 설치해 놓기

### 앱이 느리다면
- 브라우저 캐시 비우기
- Service Worker 업데이트 (개발자도구에서 `Update on reload` 체크)
